uint32_t millis ( void )

Get current millisecond count.

Returns the number of milliseconds elapsed since timer_init(). Uses atomic access (cli/sei) to safely read 32-bit counter. Counter will overflow after ~49.7 days of continuous operation.

◆ timer_init()

void timer_init ( void )

Initialize Timer0 for millisecond counting.

Configures Timer0 in CTC mode with prescaler 64. At 16MHz: 16MHz / 64 / 250 = 1000Hz (1ms period). Enables TIMER0_COMPA interrupt for incrementing counter.

Note
Must be called before sei() to ensure proper interrupt setup.
