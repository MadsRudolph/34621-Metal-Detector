Detailed Description

I2C (TWI) Driver Implementation.

Author
Original: osch (AVR freaks)
Integration: Mads Rudolph, Andreas Skaaning, Jonas Beck & Sigurd Hestbech
Date
2025-01

TWI master driver implementation for ATmega328P/Arduino Nano. Provides blocking I2C communication for SSD1306 OLED display.

Hardware Connections:
  • SDA: A4 (PC4)
  • SCL: A5 (PC5)
