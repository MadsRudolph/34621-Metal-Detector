Detailed Description

VLF Metal Detector Firmware - DTU 34621.

Author
Mads Rudolph, Andreas Skaaning, Jonas Beck & Sigurd Hestbech
Date
2025-01

Complete VLF (Very Low Frequency) metal detector implementation for Arduino Nano (ATmega328P). The system generates a 2kHz TX signal, samples the RX coil response, performs DFT analysis to extract magnitude and phase, and classifies detected metals as ferrous or non-ferrous based on phase shift.

Signal Flow

Timer0 (8kHz) -> TX Toggle (2kHz) -> Metal -> RX Coil -> ADC -> DFT -> IIR Filter -> Classification -> Display

Key Features

  • 2kHz TX signal generation via Timer0 ISR
  • 8kHz ADC sampling with auto-trigger from Timer0
  • Optimized single-bin DFT (64 samples = 8ms window)
  • IIR low-pass filter for stable readings
  • Metal classification (ferro/non-ferro) based on phase
  • EEPROM calibration persistence
  • Start/Stop control with button interface

Pin Configuration

Pin Function Description
D9 TX signal (PB1) 2kHz square wave output
A0 RX input (ADC0) Receive coil signal
A4 I2C SDA OLED display data
A5 I2C SCL OLED display clock
D2 Start/Stop button Toggle detector on/off
D3 Calibrate button Save baseline to EEPROM
D4 Debug button Toggle DFT/Debug display
