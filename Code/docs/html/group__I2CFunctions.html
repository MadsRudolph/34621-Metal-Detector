◆ I2C_Init()

void I2C_Init ( void )

Initialize TWI hardware for I2C master mode.

Configures TWI for ~308kHz SCL frequency:

  • TWBR = 18, Prescaler = 1
  • SCL = 16MHz / (16 + 2*18*1) = 308kHz
Note
Includes 1 second startup delay for display initialization

◆ I2C_Start()

uint8_t I2C_Start ( char write_address)

Generate START condition and send slave address (write).

Generates START condition, waits for completion, then sends SLA+W (Slave Address + Write bit).

Parameters
write_address8-bit address (7-bit slave addr << 1, LSB=0)
Returns
Status code:
  • 0: START condition failed
  • 1: ACK received (slave acknowledged)
  • 2: NACK received (no slave response)
  • 3: SLA+W transmission failed
