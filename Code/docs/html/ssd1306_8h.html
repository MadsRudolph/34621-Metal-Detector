Detailed Description

SSD1306 OLED Display Driver (128x64).

Author
Original: osch (Adafruit_SSD1306 library)
Integration: Mads Rudolph, Andreas Skaaning, Jonas Beck & Sigurd Hestbech
Date
2025-01

Driver for SSD1306-based 128x64 OLED display via I2C interface. Provides text display, large numbers, and graphics functions.

Hardware Connections (Arduino Nano):
Signal Arduino Pin ATmega328P Pin
VCC 5V -
GND GND -
SDA A4 PC4
SCL A5 PC5
I2C Address:
  • Write: 0x78 (0x3C << 1)
  • Read: 0x7A (0x3D << 1)
Documentation References:
  • SSD1306 Advanced Information Matrix (Apr 2008, Rev 1.1)
  • DD-2864bY-3A Rev C (p. 19) - Initialization sequence
See also
https://github.com/adafruit/Adafruit_SSD1306
