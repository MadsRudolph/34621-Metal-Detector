◆ capture_init()

void capture_init ( uint32_t baud)

Initialize UART for capture mode communication.

Configures USART0 in double-speed mode (U2X0) for more accurate baud rate generation. Sets 8N1 format (8 data, no parity, 1 stop).

Parameters
baudDesired baud rate (e.g., 115200)
UBRR Calculation:
UBRR = F_CPU / 8 / baud - 1 (double-speed mode) At 16MHz, 115200 baud: UBRR = 16000000 / 8 / 115200 - 1 = 16

Configures USART0:

  • Double-speed mode (U2X0) for better baud accuracy
  • TX and RX enabled
  • 8 data bits, no parity, 1 stop bit (8N1)
Parameters
baudDesired baud rate

Output captured data and DFT results via UART.

Outputs complete capture data in CSV format:

  • Header with sample index and value columns
  • All 64 ADC samples
  • Computed DFT results (Re, Im, Mag, Phase)
Parameters
reReal component of DFT (sum of sample * cos coefficients)
imImaginary component of DFT (sum of sample * sin coefficients)
magMagnitude = sqrt(re*re + im*im)
phasePhase angle in degrees = atan2(im, re) * 180/PI
Output Format:

--- End Capture ---
