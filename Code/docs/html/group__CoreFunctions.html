void InitializeDisplay ( void )

Initialize SSD1306 display.

Sends complete initialization sequence for 128x64 display:

  • Clock divider, multiplex, display offset
  • Charge pump (internal VCC)
  • Memory mode (horizontal addressing)
  • Segment/COM remap (180-degree rotation)
  • Contrast, precharge, VCOMH levels

Initialize SSD1306 display.

Complete initialization sequence for 128x64 display:

  • Display off during init
  • Clock divider 0x80 (default)
  • Multiplex ratio 0x3F (64 lines)
  • Display offset 0 (no offset)
  • Start line 0
  • Charge pump enabled (internal VCC)
  • Horizontal addressing mode
  • Segment remap and COM scan for 180-degree rotation
  • COM pins 0x12 (alternative config)
  • Contrast 0xCF
  • Precharge 0xF1
  • VCOMH 0x40
  • Display on
