Detailed Description

SSD1306 OLED Display Driver Implementation.

Author
Original: osc (Adafruit_SSD1306 library)
Integration: Mads Rudolph, Andreas Skaaning, Jonas Beck & Sigurd Hestbech
Date
2025-01

Implementation of SSD1306 OLED display driver for 128x64 pixel display. Uses I2C interface for communication with the display controller.

Hardware Connection (Arduino Nano):
  • SDA: A4 (PC4)
  • SCL: A5 (PC5)
Documentation:
  • SSD1306 Advanced Information Matrix (Apr 2008, Rev 1.1)
  • solomon-systech.com
See also
ssd1306.h for public interface documentation
