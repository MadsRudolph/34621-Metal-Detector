Detailed Description

Font Data for SSD1306 OLED Display.

Author
Original: osch (SSD1306 driver)
Integration: Mads Rudolph, Andreas Skaaning, Jonas Beck & Sigurd Hestbech
Date
2025-01

Static font arrays stored in PROGMEM for OLED display. Contains both large digit font and standard 8x8 ASCII font.

Font Creation:
Custom fonts can be created using: https://www.mikroe.com/glcd-font-creator
Memory Usage:
  • bigNumbers: 11 characters x 96 bytes = 1056 bytes PROGMEM
  • myFont: 96 characters x 8 bytes = 768 bytes PROGMEM
  • Total: ~1.8 KB PROGMEM
