void capture_init ( uint32_t baud)

Initialize UART for capture mode communication.

Configures USART0:

  • Double-speed mode (U2X0) for better baud accuracy
  • TX and RX enabled
  • 8 data bits, no parity, 1 stop bit (8N1)
Parameters
baudDesired baud rate
