ISR ( TIMER0_COMPA_vect )

Timer0 Compare Match A ISR - TX signal generation.

Called at 8kHz. Toggles TX pin every 2 interrupts for 2kHz output. Sets sync_flag on TX rising edge to synchronize DFT window. When detector is stopped, holds TX low to save power.
