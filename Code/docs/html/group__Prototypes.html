◆ classify_metal()

void classify_metal ( void )

Classify detected metal type.

Classification algorithm:

  1. Check if calibrated (required for classification)
  2. Calculate magnitude delta from baseline
  3. If delta < DETECT_THRESHOLD (5): no metal
  4. If phase delta < FERRO_THRESHOLD (-10°): ferromagnetic
  5. Otherwise: non-ferromagnetic

Physical basis:

  • Ferrous metals (iron, steel) have high permeability, causing negative phase shift
  • Non-ferrous metals (copper, aluminum) primarily cause eddy current losses with neutral/positive phase shift

void dft_calc ( void )

Calculate magnitude and phase from DFT result.

Computes:

  • Magnitude = sqrt(Re² + Im²) / N
  • Phase = atan2(Im, Re) * 180/π
Note
Uses floating-point math for accuracy. Could be optimized with integer approximations if needed.

◆ dft_sum()

void dft_sum ( int16_t raw)

Accumulate sample into DFT bins.

Optimized single-bin DFT exploiting 4x oversampling. At 8kHz sample rate with 2kHz signal, samples occur at 0°, 90°, 180°, 270° phase positions where cos/sin are ±1 or 0.

Coefficient mapping:

Index Phase cos(θ) sin(θ) Re Im
0 0° +1 0 Re += x -
1 90° 0 +1 - Im -= x
2 180° -1 0 Re -= x -
3 270° 0 -1 - Im += x
Parameters
rawADC reading (0-1023)

◆ filter_update()

void filter_update ( void )

Update IIR filtered magnitude and phase.

Single-pole IIR low-pass filter: y[n] = α × x[n] + (1-α) × y[n-1]

With α = 0.15:

  • Provides good smoothing with reasonable response time
  • Higher α = faster response, more noise
  • Lower α = slower response, smoother output
