Detailed Description

DFT Capture Mode for MATLAB Verification.

Author
DTU 34621 Metal Detector Project
Date
2025-01

This module provides UART-based capture functionality for verifying the DFT implementation against MATLAB. When enabled, it captures raw ADC samples during a complete DFT window and outputs them via UART in CSV format for analysis.

Usage Protocol:
  1. Connect to serial port at configured baud rate
  2. Send 'C' or 'c' to request capture
  3. Receive "ACK" confirmation
  4. Wait for complete DFT window (64 samples)
  5. Receive CSV data with samples and computed results
State Machine:
  • CAPTURE_IDLE: Waiting for serial command
  • CAPTURE_WAITING: Command received, waiting for next DFT window
  • CAPTURE_ACTIVE: Currently capturing samples
  • CAPTURE_DONE: Capture complete, ready for output
