void adc_init ( void )

Initialize ADC with Timer0 auto-trigger.

Configures ADC for:

  • AVCC reference (5V)
  • Auto-trigger from Timer0 Compare Match A
  • Prescaler 64 for 250kHz ADC clock
  • Interrupt on conversion complete

ADC timing:

  • ADC clock = 16MHz / 64 = 250kHz
  • Conversion time = 13 cycles / 250kHz = 52µs
  • Sample interval = 125µs (8kHz), margin = 73µs

◆ timer0_init()

void timer0_init ( void )

Initialize Timer0 for TX generation and ADC triggering.

Configures Timer0 in CTC mode for 8kHz interrupt rate. The ISR toggles PB1 every 2 interrupts to generate 2kHz TX signal. Timer0 Compare Match A also triggers ADC auto-conversion.

Frequency calculation:

  • f_interrupt = 16MHz / (prescaler * (OCR0A + 1))
  • f_interrupt = 16MHz / (8 * 250) = 8kHz
  • TX toggles every 2 interrupts = 4kHz toggle = 2kHz square wave
