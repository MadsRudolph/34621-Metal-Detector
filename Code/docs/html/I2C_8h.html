Detailed Description

I2C (TWI) Master Driver for ATmega328P.

Author
Original: osch (AVR freaks)
Integration: Mads Rudolph, Andreas Skaaning, Jonas Beck & Sigurd Hestbech
Date
2025-01

TWI (Two-Wire Interface) master driver for ATmega328P/Arduino Nano. Provides basic I2C communication for the SSD1306 OLED display.

Hardware Connections (Arduino Nano):
Function Arduino Pin ATmega328P Pin
SDA A4 PC4
SCL A5 PC5
Porting Note:
Adapted from ATmega2560 to ATmega328P. TWI registers (TWBR, TWSR, TWCR, TWDR) are identical between devices.
